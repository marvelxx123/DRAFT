Going Live
5 Steps to Launch

The code is done. These are the only steps left before real customers can buy from you.

1

Create a Stripe Account

Stripe handles all payments. Sign up at stripe.com, then get your keys from the Dashboard → Developers → API Keys.

stripe.com/register

You need: Secret Key (sk_live_...) and a Webhook Secret (whsec_...) — you get the webhook secret after registering your endpoint URL in Stripe's dashboard.

2

Create a Printful Account

Printful prints and ships every order. Sign up free, create a Store, and get your API key from Settings → API.

printful.com

You need: API Key and your Store ID (visible in the URL when you're in your store dashboard).

3

Get an Anthropic API Key

This powers all 6 AI agents. Sign up at console.anthropic.com and create an API key.

console.anthropic.com

Add a credit card and some balance (agents use Claude Haiku — it's very cheap, roughly $1–2/month at normal usage).

4

Deploy to Railway

Railway hosts your server. Create an account, connect your GitHub repo (marvelxx123/DRAFT), and it will auto-detect and deploy.

railway.app

Then in Railway's Variables tab, add all your keys:

STRIPE_SECRET_KEY STRIPE_WEBHOOK_SECRET PRINTFUL_API_KEY PRINTFUL_STORE_ID ANTHROPIC_API_KEY ADMIN_PASSWORD

ADMIN_PASSWORD is whatever you want — it's what you'll use to log into your Mission Control dashboard.

5

Register Your Stripe Webhook

After Railway gives you a URL (e.g. wearit-production.up.railway.app), go to Stripe → Developers → Webhooks → Add Endpoint.

Set the endpoint URL to:

https://your-railway-url.up.railway.app/api/webhooks/stripe

Select the event: checkout.session.completed

This is the connection between Stripe and Printful. When a customer pays, Stripe notifies your server, which automatically sends the order to Printful for printing.

🚀

That's It. You're Live.

Once those 5 steps are done, your store is open, agents are running, and orders are being fulfilled automatically. You just need to drive traffic — and the agents are already working on that too.
