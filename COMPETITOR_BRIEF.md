## Section 2: Location Page Blueprint

This is the exact template for every location page.

### Title Tag Format
```
Garage Door Repair [City] FL | 904 Garage Doors — Same-Day Service
```
Max 60 chars. City + state + brand + key differentiator.

### Meta Description Format
```
[City] FL garage door repair — broken springs, off-track doors, opener service. 
Licensed local tech. Same-day emergency service. Free estimate. Call (904) 468-3428.
```
Max 155 chars. Hit: city + state, problem keywords, trust signal, phone.

### H1 Format
```
Garage Door Repair in [City], FL — We Fix It Today
```
Contains: city, state, primary keyword, urgency signal.

### H2 Sections (in order)

1. **"Why [City] Homeowners Call 904 Garage Doors First"**
   — Local angle: drive time, neighborhood knowledge, coastal climate
   
2. **"Garage Door Services We Provide in [City]"**
   — Service list with city-specific copy (mention local housing types)
   
3. **"Common Garage Door Problems in [City], FL"**
   — Florida-specific issues: humidity, salt air, storm damage, sand in tracks
   — This is keyword-rich and genuinely useful
   
4. **"We're [X] Minutes from [City]"** (or "Your [City] Neighbor")
   — Drive time / local presence claim
   
5. **"Frequently Asked Questions — [City] Garage Door Repair"**
   — 3-4 questions specific to that market

6. **"Serving [City] and Surrounding Areas"**
   — Internal link chip list to neighboring cities/pages

### Keyword Density Approach
- Primary keyword (e.g., "garage door repair Yulee FL") in: title, H1, first 100 words, at least 1 H2, meta description
- Secondary keywords woven naturally into service descriptions
- Zip code mentioned at least twice (in text + schema)
- City name appears minimum 8-10 times per page

### Internal Linking Strategy
- Every location page links to 904.html (main page)
- Every location page links to the other 2 location pages in the "Areas We Serve" section
- Main 904.html should eventually link to all location pages
- Anchor text: use keyword phrases, e.g., "garage door repair in Orange Park" not just "click here"
